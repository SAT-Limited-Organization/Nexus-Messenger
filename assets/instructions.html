Make It Your Own

This document explains how to convert this example to your own app.

Since this app uses Firebase, it is not enough to just copy the code. You need to make this app use your own Firebase account.

1. Perform the following steps in the Firebase Console:

  • Create a Firebase project.
  • Create a Realtime Database. Choose the locked access rules, which default to admin-only access.
  • Enable Google Authentication.
  • Switch to the Blaze plan (required for deploying server-side code).

2. Perform the following steps in App Builder:

  • On the app logic screen, change the package name to something unique. You cannot use the original one.
  • Go to the Firebase screen for your app.
  • Select the Firebase project you created.
  • Add your app to the project.
  • Deploy your app to Firebase. If prompted, install the Termux app to run Firebase CLI for project management.
